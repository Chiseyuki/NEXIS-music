# Nexis Music

Чёрный музыкальный плеер с фиолетовым акцентом. В проекте есть Android-приложение на WebView, локальный веб-интерфейс, загрузка собственных аудиофайлов, воспроизведение, поиск, избранное и импорт/экспорт плейлистов JSON/M3U.

## Сборка APK через GitHub Actions
1. Создайте пустой репозиторий на GitHub.
2. Загрузите **содержимое** этого архива в репозиторий.
3. Откройте вкладку **Actions** и разрешите запуск workflow, если GitHub попросит.
4. Запустите `Build Android APK` через **Run workflow** либо отправьте новый commit.
5. Откройте завершившийся запуск и скачайте артефакт `Nexis-debug-apk`.

## Важно про ВКонтакте
Сейчас импорт файлов плейлиста и локальное воспроизведение работают в приложении. Подключение аккаунта VK и воспроизведение защищённых/потоковых треков из VK **не включены автоматически**: для этого нужны официальная OAuth-авторизация, разрешённые VK API методы и соблюдение ограничений платформы. Не вводите пароль VK в сторонних формах. Кнопка VK в прототипе открывает ВКонтакте, а импорт плейлистов принимает JSON/M3U-файлы, которые у вас уже есть.

## Структура
- `app/` — Android WebView оболочка.
- `app/src/main/assets/index.html` — интерфейс и локальный плеер.
- `.github/workflows/android.yml` — сборка APK в GitHub Actions.
